# ~/code — fawos

Convention: `~/code/<host>/<project>` — `<host>` is the git hosting
account/org the project lives under (e.g. `github.com`'s `roberto286`),
`<project>` is the repo name. Example: this convention itself lives in
`~/code/roberto286/fawos`.

Each project under here is expected to carry its own `AGENTS.md` at its root
if it wants AI-assistant context — this file only documents the *layout*
convention, not individual projects.
